In einigen Szenen-Aktionen kannst du Variablen einfügen und Berechnungen durchführen.

Das gilt für die folgenden Aktionen:

- Warten
- Gerätewert setzen
- Bedingung auf Variablen

In diesen Aktionen stehen dir folgende mathematische Funktionen zur Verfügung:

- `+` : Addition
- `-` : Subtraktion
- `*` : Multiplikation
- `/` : Division
- `%` : Modulo
- `^` : Potenz
- `abs(-5)` : Absolutwert (Ergebnis = 5)
- `round(5.2)` : Runden (Ergebnis = 5)
- `round(5.8, 1)` : Runden auf 1 Nachkommastelle (Ergebnis = 5.8)
- `floor(5.2)` : Abrunden (Ergebnis = 5)
- `ceil(5.2)` : Aufrunden (Ergebnis = 6)
- `random(1, 10)` : Zufallszahl zwischen 1 und 10
