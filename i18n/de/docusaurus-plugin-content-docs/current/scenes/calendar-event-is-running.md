title: Bedingung in einer Szene auf Basis eines Kalenderereignisses
description: "Füge einer Szene in Gladys Assistant eine Bedingung auf Basis eines laufenden Kalenderereignisses hinzu, damit Automatisierungen nur im Urlaub, beim Sport oder in Meetings laufen."
sidebar_label: Kalenderereignis läuft
---

Stell dir vor, du möchtest eine Szene erstellen, die nur ausgeführt wird, wenn du gerade im Urlaub, im Fitnessstudio oder in einem Telefonat bist.

Du kannst die Kalender-Integration (zum Beispiel [CalDAV](/de/docs/integrations/caldav)) nutzen, um in einer Szene eine Bedingung hinzuzufügen, die prüft, ob gerade ein Ereignis in deinem Kalender stattfindet.

Das sieht so aus:

![Bedingung: Kalenderereignis läuft](../../../../../static/img/docs/en/scenes/calendar-event-is-running/calendar-event-is-running.jpg)

Das gefundene Ereignis kannst du anschließend in weiteren Aktionen verwenden, zum Beispiel in der Aktion „Nachricht senden“:

![Variable in einer Nachricht verwenden](../../../../../static/img/docs/en/scenes/calendar-event-is-running/msg-calendar-is-running-en.jpg)
