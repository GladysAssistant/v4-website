## So funktionieren Integrationen

Gladys Assistant ist ein **Open-Source-Projekt**, entwickelt von einer **Community von Smart-Home-Begeisterten**, mit einem Ziel: ein Smart Home, das **einfach, lokal und datenschutzfreundlich** ist. Ein Gerät zu verbinden sollte weder von einer geschlossenen Cloud noch von einem einzigen Hersteller abhängen. Deshalb gibt es Integrationen in zwei Varianten, Seite an Seite im Katalog oben und im Bildschirm **Integrationen** von Gladys:

- **Native Integrationen** werden mit Gladys ausgeliefert. Sie decken die **offenen Protokolle** ab, die wir für jede neue Installation empfehlen: [Zigbee2MQTT](/de/docs/integrations/zigbee2mqtt/) für Tausende Zigbee-Geräte ohne Hersteller-Hub, [Matter](/de/docs/integrations/matter/), der Industriestandard, 100 % lokal, und [MQTT](/de/docs/integrations/mqtt/), der universelle Klebstoff für DIY-Projekte.
- **Community-Integrationen** decken alles andere ab. Jede ist ein kleines Programm, als **Docker-Container** verpackt und von einem Gladys-Nutzer auf GitHub veröffentlicht. Gladys führt sie in einer **vom Kern isolierten Sandbox** aus und spricht über eine eigene API mit ihr. So kann jeder eine veröffentlichen, in jeder Sprache und ohne Prüfung, während deine Instanz sicher bleibt.

## Eine Integration installieren

Öffne in Gladys **Integrationen**: Native und Community-Integrationen stehen dort gemeinsam, nach Kategorien geordnet. Bei einer Community-Integration klickst du auf **Installieren**: Gladys lädt das Docker-Image herunter, startet den Container und erzeugt seine Oberfläche (Geräte, Erkennung und Konfiguration). Du kannst eine Integration auch direkt über die URL ihres GitHub-Repositorys installieren.

Der Katalog in Gladys wird stündlich aktualisiert: Eine neu veröffentlichte Integration erscheint dort spätestens eine Stunde nach ihrer Veröffentlichung.

## Dein Gerät ist nicht dabei?

- Frag im [Forum](https://community.gladysassistant.com/) nach: Vielleicht arbeitet schon jemand daran.
- **Bau sie selbst**: Community-Integrationen sind der einfachste Weg, eine Integration zu erstellen und zu veröffentlichen, ohne Pull Request und ohne Prüfung. Folge dem [Entwicklerleitfaden](/de/docs/dev/external-integrations/).
- Für individuelle oder experimentelle Setups lassen sich mit [Node-RED](/de/docs/integrations/node-red/) und [MQTT](/de/docs/integrations/mqtt/) fast beliebige Dinge mit Gladys verbinden.

Der vollständige Quellcode von Gladys ist auf [GitHub](https://github.com/GladysAssistant/Gladys) verfügbar.
