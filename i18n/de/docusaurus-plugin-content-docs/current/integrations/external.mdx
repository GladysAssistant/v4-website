**Externe Integrationen** sind von der Community entwickelte Integrationen, die als Docker-Container verpackt und auf GitHub veröffentlicht werden. Sie lassen sich mit **einem Klick** aus dem Katalog in Gladys installieren und laufen in einer sicheren Sandbox, isoliert vom Kern.

Jeder kann eine erstellen und veröffentlichen, ohne Prüfung oder Freigabe durch die Maintainer: Die Liste unten wächst kontinuierlich, direkt aus der Community heraus.

Eine externe Integration kann **Geräte** (Sensoren, Schalter, Lampen, Kameras…), einen **Nachrichtenkanal** (eine Chat- oder Benachrichtigungsbrücke) oder, seit Gladys 4.85, einen **Wetteranbieter** bereitstellen, der das Wetter-Widget auf dem Dashboard, den Chat-Assistenten und die Wetterwarnungs-Szenen mit Daten versorgt.

Jede Integration hat ihre eigene Seite mit Dokumentation, Konfigurationsoptionen und Installationsschritten: Klicke auf eine Karte, um sie zu öffnen.

## So installierst du eine Integration

Öffne in Gladys **Integrationen**: Externe Integrationen erscheinen dort neben den nativen, mit einem Community-Badge. Klicke auf **Installieren** – Gladys lädt das Docker-Image herunter, startet den Container und erzeugt die passende Oberfläche (Geräte, Erkennung und Konfiguration). Du kannst eine Integration auch direkt über die URL ihres GitHub-Repositorys installieren.

Der Katalog in Gladys aktualisiert sich automatisch jede Stunde, sodass eine neu veröffentlichte Integration spätestens eine Stunde nach ihrer Veröffentlichung erscheint.

## Dein Gerät wird nicht unterstützt?

- Frag im [Forum](https://community.gladysassistant.com/) nach: Vielleicht arbeitet bereits jemand daran.
- **Bau sie selbst**: Externe Integrationen sind als einfachster Weg gedacht, eine Integration zu erstellen und zu veröffentlichen – in jeder beliebigen Programmiersprache, ohne Pull Request und ohne Freigabe. Folge dem [Entwicklerleitfaden für externe Integrationen](/de/docs/dev/external-integrations/).
