Gladys Assistant kann Sprachnachrichten auf einem Google-Lautsprecher oder einem anderen Google-Cast-kompatiblen Gerät abspielen.

## Einen Google-Lautsprecher zu Gladys Assistant hinzufügen

1. Öffne in der Gladys-Oberfläche die Integration **Google Cast**.
2. Öffne den Tab **Google-Cast-Erkennung**: Kompatible Geräte in deinem Netzwerk sollten automatisch erscheinen.

![Google-Cast-Erkennung](../../../../../static/img/docs/en/configuration/google-cast/google-cast.png)

3. Wähle dein Gerät aus und klicke auf **Speichern**.
4. Gehe dann zum Tab **Geräte** und ordne den Lautsprecher dem passenden Raum zu.

## Gladys Assistant auf einem Lautsprecher sprechen lassen

Sobald der Lautsprecher hinzugefügt ist, kannst du ihn in einer Szene mit der Aktion **Auf einem Lautsprecher sprechen** verwenden:

![Google Cast – Auf einem Lautsprecher sprechen](../../../../../static/img/docs/en/configuration/google-cast/talk-on-speaker.png)

### Wichtiger Hinweis

:::note
Diese Funktion erfordert ein **Gladys Plus**-Abonnement, da sie auf einer KI-basierten Text-to-Speech-API (TTS) beruht, die kostenpflichtig ist.

Wir würden künftig gerne eine vollständig lokale Lösung anbieten, aber derzeit gibt es keine hochwertigen Offline-Alternativen für französisches TTS.
:::
