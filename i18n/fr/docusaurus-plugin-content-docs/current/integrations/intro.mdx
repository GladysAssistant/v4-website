## Comment fonctionnent les intégrations

Gladys Assistant est un **projet open source**, développé par une **communauté de passionnés de domotique**, avec un objectif : une maison connectée **simple, locale et respectueuse de votre vie privée**. Connecter un appareil ne devrait dépendre ni d'un cloud fermé, ni d'un seul fabricant. C'est pourquoi les intégrations existent en deux saveurs, côte à côte dans le catalogue ci-dessus comme dans l'écran **Intégrations** de Gladys :

- Les **intégrations natives** sont livrées avec Gladys. Elles couvrent les **protocoles ouverts** que nous recommandons pour toute nouvelle installation : [Zigbee2MQTT](/fr/docs/integrations/zigbee2mqtt/) pour des milliers d'appareils Zigbee sans box constructeur, [Matter](/fr/docs/integrations/matter/), le standard de l'industrie, 100 % local, et [MQTT](/fr/docs/integrations/mqtt/), le liant universel des projets DIY.
- Les **intégrations communautaires** couvrent tout le reste. Chacune est un petit programme empaqueté dans un **conteneur Docker** et publié sur GitHub par un utilisateur de Gladys. Gladys l'exécute dans un **bac à sable isolé de son cœur** et lui parle via une API dédiée : n'importe qui peut en publier une, dans n'importe quel langage, sans validation, sans risque pour votre instance.

## Installer une intégration

Dans Gladys, ouvrez **Intégrations** : intégrations natives et communautaires y sont listées ensemble, par catégorie. Pour une intégration communautaire, cliquez sur **Installer** : Gladys télécharge l'image Docker, démarre le conteneur et génère son interface (appareils, découverte et configuration). Vous pouvez aussi en installer une directement depuis l'URL de son dépôt GitHub.

Le catalogue dans Gladys se rafraîchit toutes les heures : une intégration fraîchement publiée y apparaît au plus tard une heure après sa sortie.

## Votre appareil n'est pas couvert ?

- Demandez sur le [forum](https://community.gladysassistant.com/) : un autre utilisateur est peut-être déjà dessus.
- **Créez-la vous-même** : les intégrations communautaires sont la façon la plus simple de créer et publier une intégration, sans pull request et sans validation. Suivez le [guide développeur](/fr/docs/dev/external-integrations/).
- Pour les installations sur mesure ou expérimentales, [Node-RED](/fr/docs/integrations/node-red/) et [MQTT](/fr/docs/integrations/mqtt/) permettent de brancher presque n'importe quoi sur Gladys.

Le code source complet de Gladys est disponible sur [GitHub](https://github.com/GladysAssistant/Gladys).
