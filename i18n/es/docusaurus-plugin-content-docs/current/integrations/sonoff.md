Los dispositivos Sonoff se pueden usar con el firmware de código abierto [Tasmota](/es/docs/integrations/tasmota/).

Para conectarlos a Gladys:

- configura tu cuenta en la nube de eWeLink
- ve a `Integraciones / eWeLink` en Gladys

## Requisito previo

Necesitas una cuenta en la nube de "eWeLink":

- [eWeLink para Android](https://play.google.com/store/apps/details?id=com.coolkit "eWeLink para Android")
- [eWeLink para iPhone/iPad](https://apps.apple.com/fr/app/ewelink-smart-home/id1035163158 "eWeLink para iPhone/iPad")

## Añadir un dispositivo a Gladys

Una vez creada tu cuenta, vuelve a Gladys:

1. abre la página `Integraciones -> eWeLink`
2. selecciona el menú `Configuración`
3. introduce tus credenciales y guárdalas
4. selecciona el menú `Detección eWeLink`
5. haz clic en el botón `Escanear` (si el dispositivo todavía no aparece en la lista)
6. después en `Guardar`
7. ¡y listo!
