title: Activar una escena cuando cambia el estado de un dispositivo
description: "Activa una escena de Gladys Assistant cuando cambia el estado de un dispositivo, como una bajada de temperatura o una luz que se enciende, con condiciones personalizadas."
sidebar_label: Cambio de estado de un dispositivo
---

Imagina que quieres crear una escena que realice una acción concreta cuando la temperatura de una habitación determinada baje de 20 °C.

Para ello necesitas un desencadenante "Cambio de estado de un dispositivo".

Haz clic en "Nuevo desencadenante" y selecciona "Cambio de estado de un dispositivo":

![Activar una escena cuando cambia el estado de un dispositivo](../../../../../static/img/docs/en/scenes/device-state-changed-trigger/device-state-changed-trigger-1.jpg)

Selecciona la funcionalidad del dispositivo que quieres "vigilar".

Por ejemplo, en nuestro caso, seleccionaremos un sensor de temperatura de la cocina:

![Activar una escena cuando cambia el estado de un dispositivo](../../../../../static/img/docs/en/scenes/device-state-changed-trigger/device-state-changed-trigger-2.jpg)

Indica en qué condición este desencadenante debe ejecutar la escena.

En nuestro caso, queremos que la escena se ejecute si "la temperatura es inferior a 20 °C":

![Activar una escena cuando cambia el estado de un dispositivo](../../../../../static/img/docs/en/scenes/device-state-changed-trigger/device-state-changed-trigger-3.jpg)

Según el tipo de dispositivo que selecciones en este desencadenante, la interfaz se adapta. Por ejemplo, si quieres ejecutar una escena "cuando se encienda la luz de la cocina", la interfaz tendrá este aspecto:

![Activar una escena cuando cambia el estado de un dispositivo](../../../../../static/img/docs/en/scenes/device-state-changed-trigger/device-state-changed-trigger-4.jpg)
