Este desencadenante se activa cuando un usuario vuelve a casa y la casa estaba vacía antes de su llegada.

También puedes usarlo dentro de una escena para continuar solo si la casa no está vacía.

## Como desencadenante

![La casa ya no está vacía](../../../../../static/img/docs/en/scenes/house-no-longer-empty/house-no-longer-empty.png)

Para registrar la presencia de un usuario en casa, puedes leer nuestro tutorial sobre la [presencia por Bluetooth](/es/docs/integrations/bluetooth) o establecer la presencia [en una escena](/es/docs/scenes/user-presence).
