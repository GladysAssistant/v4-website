sidebar_label: La casa está vacía

Este disparador se activa cuando el último usuario sale de casa.

También puedes usarlo dentro de una escena para continuar solo si la casa está vacía.

## Como disparador

![La casa está vacía](../../../../../static/img/docs/en/scenes/house-empty/house-empty.png)

Para saber cómo definir la presencia de un usuario en casa, puedes leer nuestro tutorial sobre la [presencia por Bluetooth](/es/docs/integrations/bluetooth). También puedes definir la presencia [en una escena](/es/docs/scenes/user-presence).
