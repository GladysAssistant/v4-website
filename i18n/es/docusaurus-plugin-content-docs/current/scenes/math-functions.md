Algunas acciones de escena te permiten insertar variables y realizar cálculos.

Es el caso de las siguientes acciones:

- Esperar
- Establecer el valor de un dispositivo
- Condición sobre variables

En estas acciones tienes disponibles las siguientes funciones matemáticas:

- `+` : suma
- `-` : resta
- `*` : multiplicación
- `/` : división
- `%` : módulo
- `^` : potencia
- `abs(-5)` : valor absoluto (Resultado = 5)
- `round(5.2)` : redondeo (Resultado = 5)
- `round(5.8, 1)` : redondeo con 1 decimal (Resultado = 5.8)
- `floor(5.2)` : redondeo hacia abajo (Resultado = 5)
- `ceil(5.2)` : redondeo hacia arriba (Resultado = 6)
- `random(1, 10)` : número aleatorio entre 1 y 10
