Este desencadenante se activa cuando el usuario seleccionado ha salido de casa.

## Ejemplo sencillo

![Salida de casa](../../../../../static/img/docs/en/scenes/left-home/left-home.png)

Para definir la presencia de un usuario en casa, puedes leer nuestro tutorial sobre la [presencia por Bluetooth](/es/docs/integrations/bluetooth) o definir la presencia [en una escena](/es/docs/scenes/user-presence).
